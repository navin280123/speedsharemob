## 1. Description of Service

SpeedShare is an open-source, peer-to-peer (P2P) file sharing and storage synchronization tool built using Flutter. The Application allows users to transfer files, photos, videos, documents, and browse shared storage directly between devices connected to the same local Wi-Fi network or mobile hotspot.
